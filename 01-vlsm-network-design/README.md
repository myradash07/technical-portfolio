# VLSM Subnetting & Multi-Subnet Network Configuration

## Project Overview
This project involved designing and configuring an IPv4 network using Cisco Packet Tracer. The goal was to divide a `192.168.0.0/24` network into four departmental subnets using Variable Length Subnet Masking (VLSM).

## Objectives
- Design an IPv4 addressing scheme for four departments.
- Apply VLSM based on departmental host requirements.
- Configure router interfaces and Switch Virtual Interfaces (SVIs).
- Apply basic security configurations to network devices.

## Tools & Technologies
- Cisco Packet Tracer
- IPv4 Addressing
- Variable Length Subnet Masking (VLSM)
- Cisco IOS
- Router and Switch Configuration

## Implementation
- Designed an IPv4 addressing scheme using the `192.168.0.0/24` network.
- Applied VLSM to allocate IP addresses based on departmental host requirements.
- Configured router interfaces and Switch Virtual Interfaces (SVIs).
- Applied basic network security settings to switches and routers.
- Built and configured the network topology in Cisco Packet Tracer.

## Outcome
Developed a structured multi-subnet network design with efficient IP address allocation based on departmental requirements.
